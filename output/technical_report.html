02 / 从零理解交易

订单簿是一张持续变化的“买卖排队表”

假设有人愿意以10.00元买入，另一些人愿意以10.01元卖出。二者尚未达成一致，所以暂时都留在订单簿里。买一是当前最高买价，卖一是当前最低卖价；同价位所有剩余委托的数量加起来，就是这一档的挂单量。

术语通俗解释容易误解的地方
限价买单愿意按不高于某个价格买入不是保证按该价格成交；也可能完全不成交
主动成交新订单的价格能够触及已有对手单主动方通常付出买卖价差，较快取得成交
被动挂单暂时留在簿中，等待其他订单来成交不保证成交；还要考虑同价前面的队列
部分成交一笔订单只成交了一部分剩余数量仍可能继续排队，也可以申请撤销
成交量一笔成交的股数计一次买卖双方各扣100股，市场成交量只加100股
中间价（买一价格 + 卖一价格）÷ 2衡量价格位置的统计量，不保证能按这个价格交易

价格优先，再比较时间

买方出价越高越优先，卖方要价越低越优先；方向、价格相同时，先到达交易主机的订单优先。连续竞价中，新买单触及已有卖单时，按已有卖价成交。规则依据为上交所交易规则第3.5节。

例如：卖一10.00元有700股，卖二10.01元有500股。限价10.01元买入900股，会先成交700股×10.00元，再成交200股×10.01元；成交均价约10.0022元。它不是全部按限价10.01元成交。

一分钱为什么可能很贵？

相对价差（bp） = (卖一 − 买一) / 中间价 × 10,000；1 bp = 0.01%

同样一分钱价差，股价约5元时约20bp，股价约100元时约1bp。买盘挂得厚，只说明显示出来的数量多；它不自动意味着相对交易成本低。

自测：买一10.00、卖一10.01。如果价格完全不动，立即买入100股再卖出，费用前赚多少？

按对手报价成交，买入花1001元、卖出收1000元，亏1元；还没有计入费用。这个算术例子不代表A股可以把刚买的股票当天卖掉。

程序先按股票分组，确认其竞价消息在同一通道，再按 BizIndex 合并排序。不能只按时间排序：同一毫秒可能有多条先后相关的事件。订单号使用 OrderOriNo，对应成交的 BidOrder / AskOrder；OrderNumber 在本包中不用于关联订单。

OrderKind 的65、68、83分别是字符A、D、S的编码；A表示新增，D表示撤单，S表示状态。委托方向66/83对应B/S；成交方向则来自 BSFlag。93000030 要解读为09:30:00.030。价格由float32转成整数分，避免40.830002这样的浮点表示误差影响比较。

最关键的语义：连续竞价中的新增委托消息通常公布首次撮合后的剩余量；一次全部成交的主动单可以没有新增剩余消息。集合阶段的委托也不能假设在原始委托时刻就已实时披露。依据：LDDS接口说明2.0.9，第4.3—4.4节。这份接口说明是语义参考，课程文件的具体映射另由本地记录核实。

从你本地文件中找到的一笔真实例子

600036的订单299104在09:30:00.030先出现六条主动买入成交，股数为40,834、1,300、100、600、200、300，合计43,334股。随后业务序号347767才发布剩余12,266股的买单。两部分合计55,600股。把12,266股当原始申报量，再减去先前的43,334股，会造成错误。

历史回放因此采用：新增就加入所披露的剩余量；撤单减少对应订单；连续成交必须扣到被动单；集合成交扣双方。未出现于簿中的主动单不凭空补造。遇到被动单缺失、超量扣减或重复业务序号，程序立即报错。

06 / 一个可以解释清楚的研究问题

买盘更厚，能否抵消主动交易的成本？

先统计正常双边报价：本次连续竞价样本的相对价差中位数为 3.902 bp，一分钱价差占 78.71%。下图同时展示逐股价格与价差的关系，以及全部样本逐分钟的成交量。成交量图按股票数直接加总，不能解读为资金流入流出。

研究设计：先定规则，再看早/下午结果

盘口不平衡 I = (买一数量 − 卖一数量) / (买一数量 + 卖一数量)

固定把I≥0.5称为买盘较厚，I≤−0.5称为卖盘较厚，其余为中性。每60秒设置一个决策点，只用决策时刻减3秒以前的最新快照计算信号。入场基准取决策时刻以前的最新报价；未来标签取30秒以后第一份快照。相关报价超过6秒容差就丢弃，且不跨午休或收盘集合阶段。

这里没有拟合模型或按下午结果调参。上午作为探索段，下午作同日时间留出；因股票和交易日相同，下午不等于独立跨日样本外。阈值不是上午训练选出来的“最优参数”。

30秒是目标跨度，实际入口与未来报价取相邻快照，时间间隔会略有差异。下表把不同股票的观测合并后等权平均，可能混入股票价位、流动性和样本构成差异；不能直接解释为控制了股票差异后的预测能力或因果关系。

两种数值要分清：中间价变化 = 未来中间价/当前中间价−1；纸面买入再卖出 = 未来买一/当前卖一−1。后者已经跨了买卖价差，但仍没有费用、成交延迟、排队、数量容量和市场冲击。它不是可直接执行的A股回测。

互动：给“买盘较厚”组加上一个假设费用

自测：信号能预测未来中间价，为何还不能宣称策略盈利？

你未必能以中间价成交。主动成交需要跨价差，被动成交可能排不到、或恰好在价格转差时成交。还有费用、延迟、库存约束及风险。单日多股票观测也会相互相关；本报告不把大量观测当成大量独立交易日，不报告未经正确处理的显著性结论。

07 / 写进作业的结论与边界

本次实践能够支持的结论

  1. 订单簿可以用增量事件维护。使用正确的关联键和剩余量语义，本次日终核对与订单量守恒均通过。
  2. 有独立输入的撮合实验才适合验证撮合规则。开盘集合委托可以用于这一验证；连续历史回放本身消费了真实成交，不是预测出了这些成交。
  3. 时间标签不是共同的业务水位。日内差异如实保留，任何增加时间窗口的后续研究都应单独报告核对口径。
  4. 方向信息与可交易收益之间有执行成本。固定信号实验只是单日条件统计，没有证实稳定盈利。

若改成真实交易，最可能在哪里出问题？

实际报单到达时，看到的盘口可能已经变化；同价挂单前面还有其他订单；一次性吃掉多档会改变后续市场路径；部分成交和撤单回报之间存在时间差；错误地把当日买入数量当成可卖数量会违反持仓约束。交易规则中的资金、持仓、申报数量、价格有效范围、停复牌等也需要单独实现。

本项目的独立撮合器处理已经通过申报校验的限价单，未实现账户、T+1可卖余额、资金冻结、各种市价单和完整风控。它适合课程理解撮合内核，不能称作完整券商交易系统。纸面买卖实验不产生账户订单或真实交易。
